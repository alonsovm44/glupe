Most AI tools rewrite entire files and break working code. Glupe uses semantic containers to guarantee your architecture stays completely untouched.

The Idea: Semantic Containers

Think of it as "Docker for Logic" — but for source code. You mark exactly where AI is allowed to work using $${ }$$ blocks.

  • Your architecture stays untouched.
  • AI is strictly limited to these blocks.
  • You get precision instead of chaos.
main.cpp 
#include <iostream>
#include <vector>

void process_data(std::vector<int>& data) {
    /*
    $${
         1. Remove negative numbers
         2. Sort descending
         3. Remove duplicates
    }$$
    */
}
glupe main.cpp -fill -local

Reverse Engineer

Refine Code into Intent

Have legacy or undocumented code? Glupe's Refine feature does the exact opposite of generation. It reads your rigid, existing implementations and reverse-engineers them back into flexible, human-readable semantic containers.

  • Understand complex or undocumented legacy code instantly.
  • Convert rigid implementations back into flexible intent for easy refactoring.

Core Features

A tool built to bridge intent to implementation, making AI predictable.

Surgical AI Control

AI writes only inside designated containers. Your structure is guaranteed to remain untouched.

Cached Containers

Containers are securely hashed. Zero repeated LLM calls if the instructions haven't changed.

Self-Healing Compilation

Glupe automatically handles missing includes and type errors across multiple passes until the build succeeds.

Multi-File Generation

Easily spin up complete projects. Export specific containers to standalone files like main.cpp securely.

Powerful Utility Commands

// Fix Code glupe fix file.cpp "fix segfault"
// Explain Code glupe explain main.cpp -cloud
// Diff Changes glupe diff v1.py v2.py -cloud
// Terminal SOS glupe sos "KeyError in pandas"

Quick Installation

Choose your OS and get started in seconds.

Windows (PowerShell)
  1. Press Win + R, type cmd
  2. Type powershell and press Enter
  3. Run the command below:
irm https://raw.githubusercontent.com/alonsovm44/glupe/master/install.ps1 | iex
macOS / Linux (Bash)

Open your favorite terminal and run the installation script directly:

curl -fsSL https://raw.githubusercontent.com/alonsovm44/glupe/master/install.sh | bash

Check installation

glupe --init
