# Tree-Sitter C++ AST Wrapper Documentation

## Overview
This library provides C++ RAII wrappers for the Tree-Sitter parsing library, focusing on Abstract Syntax Tree (AST) manipulation. It simplifies memory management and interaction with Tree-Sitter's C API, specifically for C++ source code.

## Purpose
- **Simplify AST Handling**: Provide a C++-friendly interface for parsing and traversing ASTs generated by Tree-Sitter.
- **Memory Safety**: Encapsulate Tree-Sitter's manual memory management with RAII principles.
- **Language Support**: Initially supports C++ (`.cpp`, `.c`, `.hpp`, `.h`), with extensibility for other languages.

## Classes

### `TSASTNode`
**Purpose**: Lightweight wrapper for `TSNode`, representing a node in the AST.  
**Behavior**:
- **Value Type**: Does not require manual memory management.
- **Methods**:
  - `type()`: Returns the node type as a string.
  - `start_byte()`, `end_byte()`: Get byte offsets in the source code.
  - `is_null()`: Check if the node is null.
  - `get_text(const string& source)`: Extract the node's text from the source code.
  - `child_count()`: Get the number of child nodes.
  - `child(uint32_t index)`: Access a child node by index.
  - `get_raw()`: Retrieve the underlying `TSNode`.

### `TSASTTree`
**Purpose**: RAII wrapper for `TSTree`, managing the lifetime of an AST.  
**Behavior**:
- **Ownership**: Automatically deletes the underlying `TSTree` on destruction.
- **Move Semantics**: Supports move operations but disables copying to prevent double deletion.
- **Methods**:
  - `root_node()`: Returns the root node of the AST as a `TSASTNode`.

### `TSASTParser`
**Purpose**: RAII wrapper for `TSParser`, handling parser initialization and language configuration.  
**Behavior**:
- **Initialization**: Creates a new parser on construction and deletes it on destruction.
- **Language Support**: Currently supports C++ variants (`cpp`, `c`, `hpp`, `h`).
- **Methods**:
  - `set_language(const string& lang_id)`: Configures the parser for a specific language. Returns `true` if successful.
  - `parse_string(const string& source)`: Parses a source code string and returns a `TSASTTree`. Throws `runtime_error` on failure.

## Usage Example
```cpp
#include "tree_sitter_ast_wrapper.h"

int main() {
    TSASTParser parser;
    if (!parser.set_language("cpp")) {
        cerr << "Failed to set language." << endl;
        return 1;
    }

    string source = "int main() { return 0; }";
    TSASTTree tree = parser.parse_string(source);
    TSASTNode root = tree.root_node();

    cout << "Root node type: " << root.type() << endl;
    cout << "Source text: " << root.get_text(source) << endl;

    return 0;
}
```

## Error Handling
- **Parsing Errors**: `parse_string` throws `runtime_error` if Tree-Sitter fails to parse the source code.
- **Language Support**: `set_language` returns `false` for unsupported languages.

## Dependencies
- **Tree-Sitter**: Requires the Tree-Sitter library and headers.
- **C++11**: Utilizes move semantics and RAII principles.

## Extensibility
- **Language Support**: Extend `set_language` to include additional languages by adding corresponding grammar functions.
- **Custom Wrappers**: Create additional wrappers for other Tree-Sitter types as needed.
